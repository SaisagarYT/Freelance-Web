# Project Workflow & Design Rules

## 1. Git & Commit Protocol
- **NEVER** run `git commit` or commit/push to `main` (or any branch) without explicit confirmation and permission from the USER first.
- Always ask the USER before committing changes to git.

## 2. Design System & UI/UX Consistency
- **ALWAYS** analyze the entire website's existing colors, typography, micro-interactions, layout rhythms, and UI/UX conventions BEFORE creating any new sections or components.
- Ensure strict visual cohesion across all pages (palette, border tokens, typography hierarchy, monospace accents, responsive ergonomics, and SaaS-grade finish).
